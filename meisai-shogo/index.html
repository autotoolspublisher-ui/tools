STATEMENT MATCHING

明細どうしの照合

発注データと納品データのような2つの明細表を貼り付けると、同じ品番の行の数量と金額を合算してから突き合わせ、数量違い・金額違い・片方だけの品番と、同じ品番で単価が違う行を一覧にします。単価で並べ替えて目で追ったり、SUMIF やマクロを組んだりしなくても、分納で行が分かれた品番をそのまま照合でき、結果は Excel に貼り戻せます。

使い方
  1. Excelの表を、見出しの行ごと表Aと表Bに貼り付けます。
  2. 区分（一致・数量違い・金額違い・片方だけ）の一覧を確かめます。
  3. 結果をコピーして Excel に貼り戻すか、CSV で保存します。

列の選び方

キーは同じものを見分ける列です（品番＋納品日のように3列まで）。見出しの語で1つに決まる列だけを自動で選びます。決まらない列は選んでください。

照合の対象
金額の許容差
キーのそろえ方

同じキーの行は、数量・金額をそれぞれ合計してから比べます。差は「B−A」です。数量と金額の両方が違うキーは「数量違い」になります。読めない値（一式、1/2 など）や違う単位（kg と g など）があるキーは、一致と決めず「要確認」にします。

単価違いは、キー1の値が同じ行を表Aと表Bから集め、読める単価の種類が2つ以上あるキーの行をすべて一覧にします（空欄と読めない単価は種類に数えません）。品番などの値も一緒にコピーする内容では、001 や 1-2 のような値を Excel が数や日付に変えることがあります。そのときは「区分の列だけ」を使い、その表の1行目と同じ行の空いた列に貼り付けてください。

貼り付けた表は、お使いのブラウザの中だけで処理します。外部に送信したり、保存したりしません。宛名・担当者名・振込先などの書類の部分は入れず、明細の行だけを貼り付けてください。

使い方の例

発注データと納品データを照合する（分納・送料・全角の品番を含む）

入力
「例を入れる」の2つの表（表Aは発注データ6行、表Bは納品データ9行（どちらも見出しの行を除く）。BT-100 は 60個と40個に分納、NT-100 は表Bで全角の「ＮＴ－１００」、表Bに送料の行）
設定
はじめの設定のまま（見出しからキー・数量・単価・金額・品名の列が選ばれ、「送料」の行は除外します）
結果
一致 3（BT-100、WS-300、PL-010）、数量違い 1（NT-100：差 −20）、金額違い 1（BT-200：差 +100）、Aだけ 1（KB-500）、Bだけ 1（HN-900）、単価違い 1品番（BT-200 が 20 と 22）。表Bの「送料」の行は除外した行に入ります。

金額の小さな差を許して、数量は気にせず金額だけで照合する

入力
同じく「例を入れる」の2つの表
設定
照合の対象：金額だけ／金額の許容差：100
結果
BT-200 の差 +100 は許容差の内なので一致になり、NT-100 は金額の差 −100 も許容差の内なので一致になります。一致 5、数量違い 0、金額違い 0、Aだけ 1、Bだけ 1 です。

よくある質問

分納で同じ品番が何行かに分かれていても照合できますか？

はい。同じキーの行は、数量と金額をそれぞれ合計してから比べます。たとえば表Aの BT-100 が100個で、表Bの BT-100 が60個と40個の2行なら、数量は一致します。

キーの列はどう選びますか？表記が違う品番（A-100 と A100 など）は同じものになりますか？

見出しの語が「品番」「商品コード」などに完全に合う列が1つだけのときは、自動で選びます。候補が複数あるときや見出しがないときは自動で選ばないので、「列と照合の設定」で選んでください。キー2・キー3を選ぶと、3列までの組み合わせで照合します（表Aと表Bで列の数をそろえます）。表記は、全角と半角、大文字と小文字、前後の空白の違いだけをそろえます。ハイフンや途中の空白の違いは「ハイフン・途中の空白を無視」を選んだときだけで、似た名前を推定して結び付けることはしません。そろえれば同じになるキーがあるときは、まとめで知らせます。

数量も金額も違うときや、読めない値があるときの区分はどうなりますか？

判定は、片方だけ → 要確認 → 数量違い → 金額違い → 一致の順です。数量と金額の両方が違うキーは「数量違い」で、一覧で金額の差も見られます。100円×10個と1,000円×1個のように金額だけ同じなら「数量違い」です（対象を「金額だけ」にすると一致です）。「一式」や「1/2」のような数と読めない値、kg と g のように違う単位の数量があるキーは「要確認」にします。空欄は 0 として合計し、そのことをまとめに出します。

送料や値引の行は、どう扱われますか？

品名の列またはキーの列の値が「除外する行」の語（はじめは 送料、値引、小計、合計）で始まる行は、照合から外します。語で始まる別の品名（「送料込みセット」など）も外れるので、一覧の「除外・キーなしの行」で確かめ、語を直してください。語を空にすると、除外しません。

入力した内容は、どこかに送信されますか？

いいえ。照合はすべてお使いのブラウザの中で行い、貼り付けた表が外部に送信されることはありません。ブラウザに保存することもありません。
