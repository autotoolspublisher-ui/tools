表マークダウン変換

ExcelやGoogleスプレッドシートの表をMarkdownの表に、ChatGPTなどのAIが出したMarkdownの表をExcelに貼れる形に変換します。

使い方
  1. 下の「変換の向き」を選びます（初めは「Excel → Markdown」）。
  2. 入力欄に表を貼り付けます。結果が自動で表示されます。
  3. 「結果をコピー」でコピーして、使いたい場所に貼り付けます。

変換の向き
0行
結果（Markdownの表）
入力欄に表を貼り付けると、ここに結果が表示されます。

列の揃え

1行目を見出しにします。セルの中の「|」は「\|」に、セル内の改行は「<br>」にします。列の数がそろわない行は、空のセルを足して、最も多い列の数にそろえます。

文章の中に表がまじっていても、表の部分だけを取り出します。「\|」は「|」に、「<br>」はセル内の改行に戻します。全角の「｜」は区切りとして扱いません。表が2つ以上あるときは、表と表の間に空の行を1行入れます。

ブラウザ内で処理します。 入力した表は、このページの中だけで処理され、保存も外部への送信もされません。

使い方の例

Excelの表をMarkdownの表にする

入力
商品	価格	在庫
りんご	120	あり
バナナ	98	なし

Excelで3行×3列のセル範囲を選んでコピーしたもの（列の間はタブ）

設定
Excel → Markdown／列の揃え：指定なし／列の幅をそろえる：オン（初期設定のまま）
結果
| 商品   | 価格 | 在庫 |
| ------ | ---- | ---- |
| りんご | 120  | あり |
| バナナ | 98   | なし |

AIの答えにある表をExcelに貼れる形にする

入力
候補を比べました。

| 案 | 費用 | おすすめ度 |
|---|---|---|
| A案 | 3万円 | **高** |
| B案 | 5万円 | 中 |

ほかにも質問があればどうぞ。
設定
Markdown → Excel／太字などの記号を外す：オン（初期設定のまま）
結果
案	費用	おすすめ度
A案	3万円	高
B案	5万円	中

列の間はタブです。Excelのセルを1つ選んで貼り付けると、3行×3列の表になります。前後の文章と「**」は除かれます。

よくある質問

Googleスプレッドシートでも使えますか？

はい。スプレッドシートでセル範囲を選んでコピーし、入力欄に貼り付けるとMarkdownの表になります。「Markdown → Excel」の結果も、スプレッドシートのセルを1つ選んで貼り付けると列に分かれます。

セルの中の改行や「|」はどうなりますか？

「Excel → Markdown」では、セル内の改行を「<br>」に、「|」を「\|」にして、表が崩れないようにします。「Markdown → Excel」では逆に、「<br>」をセル内の改行に、「\|」を「|」に戻します。

ChatGPTなどのAIの答えを、そのまま貼り付けてもいいですか？

はい。「Markdown → Excel」では、前後の文章は除いて表の部分だけを取り出します。表が2つ以上あるときは、表と表の間に空の行を1行入れて並べます。「太字などの記号を外す」がオン（初期設定）のときは、**太字** などの記号を外して中の文字だけにします。

「列の幅をそろえる」とは何ですか？

テキストのままでも表に見えるよう、各列の幅を空白でそろえます。全角の文字は半角2文字分として数えます。フォントによっては少しずれることがありますが、Markdownとして表示したときの表の中身は変わりません。オフにすると空白を足さず、短く出力します。

入力した表は、どこかに送信されますか？

いいえ。変換はすべてお使いのブラウザの中で行われ、入力した内容が外部に送信されたり、保存されたりすることはありません。

ほかのツール

  • 区切り変換くんカンマや改行で並んだリストを、好きな区切り方にまとめて変換します。
  • まとめて置換置換リストを使って、複数の語句を一度に置き換えます。入れ替えや改行への置換もできます。
  • 全角半角そろえ全角と半角が混ざったテキストを、英数字は半角・カナは全角のように、文字の種類ごとにそろえます。
  • リスト比較2つのリストを比べて、両方にある項目と、片方にしかない項目を抜き出します。
  • 改行削除PDFなどからコピーした文章の余計な改行を消して、1つの文章につなげます。段落や箇条書きの改行は残せます。
  • ひらがなカタカナ変換ひらがなをカタカナに、カタカナをひらがなにまとめて変換します。名簿のふりがなの表記をそろえるときに使えます。
  • 機種依存文字チェック①や㈱、髙などの機種依存文字や、Shift_JISのCSVで「?」になる文字を探して、使える文字に置き換えます。
  • 漢数字変換文章の数字を漢数字（二〇二六・二千二十六）に、Excelの列の漢数字を数字に、まとめて変換します。
