配信予定をカレンダーに

スプレッドシートの1週間分の配信予定を貼り付けると、カレンダーに取り込める .ics ファイル、Googleカレンダーの登録URL、X の告知文、Markdown の表を一度に作ります。1件ずつフォームに入れるカレンダー作成ツールや、告知文・表を別々に手で書く方法と違い、表をそのまま使えます。年の書かれていない日付は決まった方法で年を補い、年末年始の登録の間違いを防ぎます。

使い方
  1. 配信予定の表（日付か曜日・開始時刻・タイトル）を貼り付けます。
  2. 曜日だけの表なら、「週の開始日」で今週か来週を選びます。
  3. 「.ics を保存」でカレンダーに取り込むか、告知文をコピーします。

結果

  • 予定–
  • 期間–
  • 休み・未定–
  • 読めない行–

表示する結果

「Googleカレンダーに追加」を押すと Googleカレンダーが開き、その予定の名前・日時・配信先が Google に渡ります。押さなければ、どこにも送られません。


          

          

          

            
          

        

        

          
Markdown は、note・GitHub・ブログなどに貼ると表になる書き方です。表をコピー（Excel）は、Excel・スプレッドシートに貼る形です。

          告知文のひな形
          

            
            
            
          

          
差し込める名前：{月} {日} {曜日} {開始} {終了} {タイトル} {配信先} {配信者名}。お休みの日は {開始} が「お休み」、時間未定は「時間未定」になります。

          

            
          

        

        

          列の割り当て
          

            
            
            
            
            
          

          
はじめは見出しの言葉（日付・曜日・開始・タイトル・配信先・終了など）か、中身から自動で選びます。タブのない行は「日付 時刻 タイトル」の順に空白で区切って読み、最後の語が URL なら配信先にします。

        

      

    


    
日付は 2026/10/27・10/27・10月27日（曜日つきも可）、曜日だけ（月・月曜・Mon）を読みます。時刻は 21:00・21時・21時30分・午後9時、24時以降（25:00）は翌日の時刻として登録します。開始が「休み」の日は登録せず告知文と表にだけ入れ、「未定」は終日の予定にします。時刻はすべて日本時間です。

    
貼り付けた予定と配信者名は、お使いのブラウザの中だけで処理します。外部に送信したり、保存したりしません（「Googleカレンダーに追加」を押したときだけ、その予定が Google に渡ります）。

よくある質問

    

      どんな書き方の日付・時刻を読めますか？
      
日付は「2026/10/27」「2026年10月27日」「10/27」「10月27日」（後ろに(月)などの曜日が付いてもよい）、曜日だけの「月」「月曜」「Mon」を読みます。時刻は「21:00」「21時」「21時30分」「午後9時」を読み、「21:00〜23:00」のような範囲も読みます。全角の数字・記号も読みます。「1/2/3」のように順番が決まらない形や、ない日付（2/30）は読まず、読めない行として行番号を知らせます。

    

    

      年が書いていない日付は、何年になりますか？
      
「週の開始日」と同じ年にします。その年の日付が週の開始日より前になるときは、翌年にします。たとえば週の開始日が 2026/12/28 のとき、「12/31」は 2026/12/31、「1/2」は 2027/1/2 になります。週の開始日から7日の外になった日付は、まとめで知らせます。曜日だけの行は、週の開始日から7日の中の同じ曜日にします。

    

    

      「25:00」のような深夜の時刻や、お休みの日はどうなりますか？
      
24時以降の時刻は、翌日の時刻としてカレンダーに登録します（10/31(土) の 25:00 は 11/1(日) の 1:00）。告知文と Markdown の表には、書いたとおり「25:00」で出します。開始の欄が「休み」「お休み」の日は、カレンダーには登録せず、告知文と表にだけ「お休み」として入れます。「未定」「時間未定」の日は、終日の予定として登録します。

    

    

      作った .ics ファイルは、どうやってカレンダーに入れますか？
      
Googleカレンダーは、パソコンのブラウザで「設定 › インポート / エクスポート」からファイルを選びます。iPhone は、保存したファイルを開いて「すべてを追加」を押します。Outlook は、ファイルを開いて取り込みます。1件ずつ入れたいときは、日時の一覧の「Googleカレンダーに追加」を押すと、その予定の入力画面が開きます。時刻はすべて日本時間で登録します。

    

    

      入力した内容は、どこかに送信されますか？
      
いいえ。表の読み取りとファイルの作成は、すべてお使いのブラウザの中で行い、貼り付けた予定や配信者名が外部に送信されることはありません。ブラウザに保存することもありません。ただし「Googleカレンダーに追加」を押したときは、その予定の名前・日時・配信先が URL として Google に渡ります。
